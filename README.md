# AproVerta+

**Más aprovechamiento, más oportunidades.**

AproVerta+ es una propuesta de aplicación que busca ayudar a pequeños y medianos vendedores de frutas y verduras a reducir las pérdidas de productos mediante herramientas digitales.

## Funciones del prototipo

- Registro de productos: identificación de productos y estado de maduración.
- Conservación: información sobre frutas climatéricas y no climatéricas.
- Negocio digital: creación de un espacio para mostrar productos, promociones y ofertas.
- Publicación de excedentes: conexión entre vendedores y personas interesadas en aprovechar productos que no lograron vender.
- Clientes: búsqueda de negocios y acceso a sus novedades.

## Tecnologías

- Lenguaje C.
- CS50 Library.

## Estado del proyecto

Este repositorio contiene una primera versión experimental desarrollada en C. Representa una parte de la lógica y las funcionalidades que se proyectan para la aplicación completa.

## Objetivo

Contribuir a la reducción de las pérdidas de alimentos y apoyar la gestión de pequeños y medianos negocios mediante la tecnología.
